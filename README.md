# DataSorter
**DataSorter** — консольное Java-приложение для обработки и сортировки данных о сотрудниках и менеджерах из файлов с расширением .sb. Программа объединяет данные по департаментам, сортирует их по заданным параметрам, генерирует статистику и сохраняет результаты в файлы.

## Требования
Java версии 16

Gradle версии 8.13
## Запуск прогрммы 
Запуск из командной строки:
java -jar path/to/out/artifacts/DataSorter_jar/DataSorter.jar [параметры]

Программа поддерживает запуск без параметров. В этом случае она выполняет следующие действия:

- Обрабатывает все файлы с расширением .sb в текущей рабочей директории.
- Создаёт для каждого департамента файл <department_name>.sb, содержащий отсортированные данные сотрудников.
- Выводит информацию о некорректных или нераспознанных данных в файл error.log.
## Ввод аргументов при запуске

Если при запуске программы вы получите сообщение об ошибке, например:

Invalid arguments: Unknown Order Please enter the correct arguments:
Это означает, что были введены некорректные аргументы.

**Важно:**  
При повторном вводе аргументов не нужно указывать команду запуска java -jar DataSorter.jar  
Вводите только параметры, например:

-s=salary --order=asc --stat --path=output/statistics.txt



## Параметры командной строки

| Параметр   | Альтернативный вариант | Обязательный                | Допустимые значения | Описание                                                                               |
|------------|---------------------|-----------------------------|-----------|------------------------------------------------------------------------------------------|
| --sort     | -s                  | Нет                         | name, salary | Тип сортировки сотрудников: по имени или зарплате. Если не указано — данные выводятся без сортировки. |
| --order    | —                   | Нет                         | asc, desc | Порядок сортировки. Используется только вместе с --sort.                               |
| --stat     | —                   | Нет                         | —         | Включает генерацию статистики по департаментам.                                        |
| --output   | -o                  | Нет (обязателен при --path) | console, file | Способ вывода статистики: в консоль или в файл. По умолчанию — console.                |
| --path     | —                   | Да, если --output=file      | <путь>    | Путь к файлу для сохранения статистики. Без --output=file — ошибка.                    |
| **Другие параметры** | —                   | —                           | —         | Любые неизвестные параметры считаются ошибочными.                                        |


## Примеры запуска
Запуск с сортировкой по зарплате по возрастанию, с генерацией статистики и выводом в файл:

java -jar DataSorter.jar -s=salary --order=asc --stat --o=file --path=output/statistics.tx

Запуск с сортировкой по имени по убыванию, без статистики, вывод в консоль:

java -jar DataSorter.jar --sort=name --order=desc

Запуск только для генерации статистики в консоль:

java -jar DataSorter.jar --stat

## Уточнение по входным файлам
**Входные файлы** с расширением .sb должны находиться **в той же директории**,из которой запускатеся программа.

**Важно**

Путь к файлам не указывается явно в параметрах, программа ищет их в текущей рабочей директории.

Поэтому перед запуском убедитесь, что все необходимые файлы находятся в той же папке, из которой вы запускаете команду.
## Правила обработки данных

Если в данных встречаются:

- Два одинаковых менеджера, или
- Два менеджера, относящихся к одному департаменту,

такие записи считаются некорректными и записываются в файл error.log.
